This is an example note. Files in `_drafts/` are **not** published.

To publish a note:

1. Copy this file to `notes/my-note-title.md` and change the title, summary and text.
2. Add an entry to the `notes` list in `data/profile.json`:

```json
{ "title": "What five years of code taught me about delivery", "date": "12 Nov 2026",
  "summary": "One line that makes people want to read it.", "url": "/notes/my-note-title/" }
```

The Notes section on the home page appears as soon as that list has an entry.
